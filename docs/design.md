# Visual direction

Inspired by the two supplied references: black canvas, restrained navigation, oversized sans-serif typography with selective editorial italic serif, generous whitespace, layered product panels, and subtle edge lighting. Original layout and copy; no copied logos, images, or page recreation.

Palette: canvas #050608, surface #0D1117, blue #2589FF, white #F8FAFC, secondary #A3AAB8. Use blue glow for concierge intelligence and active focus. Keep non-AI information quieter. Avoid excessive glass, rainbow gradients, stock photography, and dense analytics dashboards.

System fonts avoid runtime font downloads. CSS contains design tokens and responsive breakpoints. Preserve English copy and `lang=en`; introduce localization centrally later. The reference images were inspected but are not distributed in the repository.

Official implementation references: https://nextjs.org/docs/app/getting-started/installation and https://tailwindcss.com/docs/installation/framework-guides/nextjs.
