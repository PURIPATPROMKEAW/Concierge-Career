“Students know which careers interest them, but comparing every job requirement with their background takes work. Concierge-Career makes that relationship visible.” Explain that jobs are fictional and the landing preview is illustrative.

## 0:30–1:15 — Understand the person

Select **Try demo profile**. Show Puripatjudhai's seven skills, three projects, Computer Engineering education, and internship. Proficiency is editable, not a scientific percentage inferred from a resume. “Only after understanding the profile do we choose a direction.” Select **Choose Career Interest → Frontend Developer**.

## 1:15–2:15 — Explain the comparison

Show eight analyzed positions and readiness **78**. One role initially qualifies as Ready to Apply; all eight have at least strong alignment in this calibrated sample. Open NovaTech (**87**) and inspect skill comparisons and score weights. These scores are alignment, not the probability of an offer.

## 2:15–3:15 — Find the next step

Open Skill gaps: TypeScript ranks first because of repeated weighted deficits. React is developing; TypeScript and Testing are absent. Open My learning and TypeScript Fundamentals. Activities are linked to canonical skills, not randomly recommended.

## 3:15–4:15 — Show adaptation

Select **Complete demo learning**, which explicitly simulates Intermediate TypeScript. Readiness changes **78 → 85**, best match **87 → 92**, ready-to-apply jobs increase, and **Frontend Testing** becomes the next priority.

“The recommendation changes because the profile changes, using the same transparent engine.”

## 4:15–5:00 — Close

Optionally explore alternatives or ask the contextual Concierge. It explains the current comparison and never invents scores. “The system understands me, shows where I fit, explains the gaps, and responds when I improve.”
